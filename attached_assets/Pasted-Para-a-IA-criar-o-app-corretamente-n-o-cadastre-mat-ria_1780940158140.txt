Para a IA criar o app corretamente, não cadastre matérias fixas dentro das telas.

Cadastre uma estrutura dinâmica:

```json
Concurso
 ├─ Nome
 ├─ Categoria
 ├─ Matérias
 │    ├─ Matéria 1
 │    ├─ Matéria 2
 │    ├─ Matéria 3
 │    └─ ...
 └─ Banco de Questões
```

Assim o mesmo aplicativo funciona para qualquer concurso.

# Estrutura que a IA deve usar

Ao selecionar:

**ESA**

O sistema cria automaticamente:

```json
[
 "Matemática",
 "Português",
 "História",
 "Geografia",
 "Inglês",
 "Redação"
]
```

Ao selecionar:

**EEAR**

```json
[
 "Matemática",
 "Física",
 "Português",
 "Inglês"
]
```

E todas as telas passam a se adaptar automaticamente:

* Home
* Estatísticas
* Desempenho
* Ranking
* Revisão
* Simulados
* Plano de Estudos
* Relatórios

Ou seja:

**não existe Home da ESA nem Home da EEAR.**

Existe uma única Home dinâmica que lê as matérias do concurso selecionado e monta tudo automaticamente. Isso vai permitir que você adicione novos concursos no futuro sem precisar criar novas telas.
